## Overview
This portfolio is a high-performance, SEO-optimized web application built with **Astro** and **React**. It serves as a showcase of my technical journey, featuring my work with **Shopify Liquid**, **Node.js**, **Python**, and more.

### Key Features
- **Cyber Emerald Theme:** A custom-designed dark interface with emerald neon accents.
- **Dynamic Projects:** Modular project cards with live architecture diagrams.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop.
